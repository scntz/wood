# Community conduct

wood welcomes contributors with different backgrounds and levels of experience.
Discuss code and evidence respectfully. Explain disagreements, accept corrections,
and make room for people learning the language and toolchain.

Harassment, threats, discriminatory abuse, impersonation, spam and disclosure of
someone's private information are unacceptable. Do not post credentials, private
source or exploit details in public discussions. AI-generated contributions must
meet the same provenance, correctness and review standards as other work.

Maintainers may edit/remove abusive content, close disruptive discussions, or
restrict participation using the repository host's moderation tools. Decisions
should be proportionate and protect affected people. Use GitHub's reporting
tools for abuse; avoid public retaliation or disclosure of private reports.
For software vulnerabilities, use [the security policy](SECURITY.md).

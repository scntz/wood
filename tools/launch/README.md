# Launching wood 1.0.0

The launch steps, in order. Each one is the owner's to take.

## 1. Publish the release

`v1.0.0` is tagged, and the release has its ten files. `docs/publishing.md` says how they were made and checked.

## 2. Make the repository public

Done. [Making the repository public](../../docs/publishing.md#making-the-repository-public) lists the commands, which also turn on
private vulnerability reporting and secret scanning.

## 3. Check and announce

- From a machine with no GitHub sign-in, follow `docs/publishing.md` step 4: download and verify the files, install, and run `wood add wood@image`.
- The announcement text is in [announcement.md](announcement.md).

# wood 1.0.0

wood is a native programming language: simple syntax, static types, and standalone executables with no runtime to install.
This release is for Windows x86-64 and Linux x86-64. The language version is 0.4.0 and the native runtime is ABI 4.
See [stability and compatibility](../stability.md) for what 1.0 promises and what is not done yet.

## What is in it

- **A compiler written in wood.** It rebuilds itself through a three-stage bootstrap that must reproduce identical bytes, and emits LLVM IR. Ordinary builds need no C++ compiler and no Python.
- **Checked by default.** 64-bit integers and indexing are checked, and values copy on write.
- **A standard library of 22 native modules,** covering files, JSON, CSV, typed arrays, elementary math, TCP and HTTP, and tasks.
- **Readable errors.** Compile and runtime errors name the file, line, column and a code, and `wood explain` describes every code.
- **Packages.** `wood add` for catalog packages, GitHub repositories and Python packages, with a `wood.lock` that pins every source.
- **Editor support.** `wood lsp`, and a VS Code extension with the compiler's own diagnostics, completion, navigation and safe rename.
- **Installers.** A Windows setup wizard, with LLVM tools included, a Linux installer, and portable archives.
- **Benchmarks.** Nine programs in wood, C++, Rust, Go, Java and Python, with every sample published, including the tests wood loses. See [performance](../performance.md).

## Known limits

Read the [known limitations](../known-limitations.md) before relying on wood. In short: Windows files are not code signed, a clean machine has not been
tested, TLS and HTTPS need OpenSSL 3 installed separately, and the GUI, audio, image, process, log and config packages and Python interoperability are experimental.
